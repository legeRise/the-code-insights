EzTajweed is a Quran learning application built and published for Android. It combines an interactive IndoPak 16-line Mushaf with ayah-level navigation, audio, translations, Tajweed explanations, and quiz-based practice.

## Stack

React Native, Django REST Framework, PostgreSQL, and Cloudflare R2.
